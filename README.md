# Neha Rani Daimary — Developer Portfolio

A responsive personal portfolio built with React and Vite. It includes an introduction, about section, technical skills, education and MERN training, selected projects, certifications, contact links, and a downloadable resume.

## Run locally

1. Install Node.js (LTS).
2. Extract this ZIP and open the project folder in VS Code.
3. Open the VS Code terminal and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Build for deployment

```bash
npm run build
npm run preview
```

The production website is generated in the `dist` folder.

## Publish online with Vercel

1. Create a GitHub repository and upload the extracted project files.
2. Sign in to Vercel using GitHub and choose **Add New → Project**.
3. Import the portfolio repository. Vercel should detect Vite automatically.
4. Keep the build command as `npm run build` and output directory as `dist`.
5. Select **Deploy**. Vercel will provide a public website URL.
